# Loan Flow

Fluxo atual de empréstimo:

1. O usuário informa o ID do livro.
2. O sistema verifica se o livro existe.
3. O sistema verifica a disponibilidade.
4. O empréstimo é registrado quando permitido.
5. O prazo de devolução depende do tipo de usuário.

Documento descritivo; nenhuma regra do CRUD foi alterada.
