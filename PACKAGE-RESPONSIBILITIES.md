# Package Responsibilities

Resumo das responsabilidades atuais:

- `model`: entidades principais do domínio.
- `service`: regras de gerenciamento da biblioteca.
- `usuarios`: hierarquia e perfis de usuário.
- `emprestimo`: operações e resultados relacionados a empréstimos.
- `interaction`: interação com o usuário e servidor HTTP experimental.

A organização do código permanece exatamente como está.
